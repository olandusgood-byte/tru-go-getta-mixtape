# V1.4 City Event Progression

Additive progression slice on the existing V1.4 City Life + Player Feedback systems.

- Adds `first-event` for completing the first City Event.
- Adds `city-veteran` for completing all five City Event types.
- Preserves `tgg-progression-v1` and `tgg-events-v1` as the existing sources of truth.
- City Event completion now synchronizes progression after the event state is saved.
- Progression UI reports City Events as `completed/5`.
- QA verifies both milestone definitions and event-to-progression synchronization.
- Browser smoke deterministically completes all five event types and verifies both milestones.
- No new persistence key, economy rule, inventory rule, district rule, or production release.
