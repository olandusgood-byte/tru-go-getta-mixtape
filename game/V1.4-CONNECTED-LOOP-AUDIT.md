# V1.4 Connected Loop Audit

## Scope
Career → level → districts → expansion → progression.

## Findings
- Career upgrades and gameplay progression continue to drive the existing player level.
- District state is derived from player level and persisted under `tgg-districts-v1`.
- District unlocks feed the existing progression achievement system.
- Expansion activities use the same level thresholds as their districts, but previously did not explicitly verify the district API before running.

## Hardening target
Expansion activities should confirm their mapped district is actually unlocked before execution, while retaining the existing level and economy checks.

## Safety
- Existing save keys remain unchanged.
- No new reward/economy path.
- No production release.
