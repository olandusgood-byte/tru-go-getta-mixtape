# V1.4 Crew Progression Vertical Slice

Crew recruitment now participates in the existing progression system.

- Recruiting the first crew member unlocks **Build The Team**.
- Recruiting all three existing crew members unlocks **Full Squad**.
- The existing `tgg-crew-v1` state remains the source of truth.
- Crew recruitment synchronizes the existing `tgg-progression-v1` state.
- Existing crew bonuses and economy behavior are unchanged.
- Deterministic browser smoke verifies both crew milestones.
- No new reward economy or duplicate crew state is introduced.
- Production remains gated.
