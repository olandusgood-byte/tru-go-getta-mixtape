# V1.4 Inventory Gameplay Vertical Slice

## Goal
Make the existing persistent inventory affect gameplay without introducing a second inventory state.

## Existing source of truth
- Inventory: `tgg-inventory-v1` / `window.TGGInventory`
- Content missions: `tgg-content-v1` / `window.TGGContent`
- City events: `tgg-events-v1` / `window.TGGEvents`

## Slice
- Flyer Run requires Promo Flyers.
- Studio Session requires Mic.
- Mixtape Promo requires Beat Pack.
- Street Cypher requires Notebook.
- Studio Pop-In requires Mic.
- Release Rush requires Beat Pack + Promo Flyers.
- Successful mission/event completion consumes the required items.
- Missing items block the action with a clear message.
- Starter inventory remains compatible, so fresh players can immediately test the loop.

## Safety
- No new inventory save key.
- No reward/economy changes.
- Existing V1.3 save compatibility preserved.
- No duplicate state store.
- Production remains gated.
