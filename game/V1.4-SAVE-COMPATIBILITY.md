# V1.4 Save Compatibility Hardening

## Scope
Harden the existing V1 save validator without changing gameplay rules, save-key names, reward values, or production behavior.

## Guarantees
- Existing `tgg-*-v1` keys remain unchanged.
- Missing subsystem saves remain valid for fresh games.
- Malformed known state is repaired to safe schema defaults.
- Valid player progress is preserved during repair.
- Collection state is normalized without duplicate entries.
- City Event `lastReward` is preserved when valid.
- Browser QA covers compatibility reporting and malformed-save repair.

## Safety
No destructive migration, force push, duplicate branch, or production release.
