# V1.4 Vertical Slice — Career Milestones

## Purpose

Connect the existing career system to the existing progression layer without replacing either system.

## Existing source of truth

- Career state: `tgg-career-v1`
- Progression state: `tgg-progression-v1`
- Career API: `window.TGGCareer`
- Progression API: `window.TGGProgression`

## Slice

When an existing career milestone is reached, sync the progression system so the player receives the existing achievement/unlock feedback.

Milestones to evaluate using existing APIs:

- first recorded track
- first released mixtape
- first studio upgrade
- career/studio level increase

## Rules

1. Do not create a second career state.
2. Do not create a second achievement state.
3. Do not alter current cash/XP/REP reward values.
4. Do not duplicate reputation rewards.
5. Existing save keys must remain compatible.
6. Missing progression state must remain repairable by the existing save validator.
7. Browser smoke must prove the existing V1.3 career loop still works.

## Acceptance criteria

- Career API remains available.
- Progression API remains available.
- Recording a track still increments recordings and reputation exactly once.
- Releasing a mixtape still requires three recordings and increments mixtapes/reputation exactly once.
- Studio upgrade still charges the existing cost and increments upgrades exactly once.
- Career level-up still unlocks the existing studio unlock.
- Progression sync does not duplicate rewards or corrupt save state.
- V1.3 browser smoke remains green.

## Status

Planning checkpoint only. Implementation should be made on a dedicated V1.4 feature branch from the stable V1.3 checkpoint.
