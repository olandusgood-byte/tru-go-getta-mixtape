# TRU GO GETTA GAME — V1.5 Full Upgrade

Branch: `feature/v1-5-full-upgrade`
Base: `game/v1-2-build`

## Upgrade scope

V1.5 hardens the core runtime without changing the existing V1 save contract or production state.

### Core runtime
- Safer player-save parsing.
- Save failures are caught instead of crashing the game.
- Existing `tgg-game-v1` save key remains unchanged.
- Visibility/page lifecycle saves protect progress when the tab is backgrounded or closed.
- Screen routing now falls back safely to the main menu for invalid screen IDs.
- DOM updates tolerate missing optional elements instead of throwing.
- Runtime errors and rejected promises are isolated and surfaced through the existing toast channel.
- A cross-system `window.TGGQuality` API now exposes runtime state, save status, API readiness, save-now, and sync-all operations.

### QA
- Release QA gains V1.5 runtime-hardening checks.
- QA verifies the existing `tgg-game-v1` save contract is still intact.
- QA verifies the new quality runtime API is loaded and exposes its required methods.

## Safety rules
- No new save keys.
- No destructive migration.
- No production changes.
- Existing V1.4 gameplay, district gating, inventory, crew, economy, events, mission chains, progression, and save keys remain the source of truth.
- Production remains gated until the separate production-verification gates are cleared.
